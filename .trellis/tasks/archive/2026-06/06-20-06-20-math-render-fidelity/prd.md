# 修复学术文档渲染:货币 $ 误判公式 + 公式溢出/编号重叠

## Goal

修复阅读真实学术论文 Markdown 时两类高频渲染缺陷,使含货币金额、宽 display 公式与带编号公式的文档正确呈现。复现样本:`samples/GoS.md`、`samples/HiPER.md`。

## Background / 根因

1. **货币 `$` 被当成行内公式定界符**(GoS.md)。底层 `micromark-extension-math@3.1.0`(remark-math 6)的 `$` 守卫只防 `$$`,无货币保护:任意 `$…$` 都解析为行内公式。文档里 `($0.94/case)…($0.10 vs. $0.94)` 这类货币对被配对,中间整段英文被吞进 KaTeX —— 数学模式吃掉空格(文字粘连)且不换行(溢出右边界)。
2. **宽 display 公式溢出 + `\tag` 编号重叠 + 行距过紧**(HiPER.md)。项目只引入 `katex/dist/katex.min.css`,无任何 `.katex-display` 覆盖。KaTeX 默认不给 display 公式横向滚动:公式 (19)(20) 宽于列宽时溢出,`\tag{}` 编号定位在公式右缘,溢出后压到内容上;连续 display 公式上下间距偏紧。

## Requirements

- R1 货币 `$` 不再触发行内公式:形如 `$0.94`、`$16.05`、`$29.2`、`$1,000.00`(`$` 紧跟 `数字[,数字组].数字`、中间无空格)的金额按字面渲染。
- R2 不得误伤真公式:`$0 = b_{0} < \dots$`(数字开头)、`$1 . 0$`(点周围有空格)等必须仍按公式渲染。
- R3 预处理必须跳过代码:围栏代码块(``` 与 ~~~)与行内 `` `code` `` 内的 `$16.05` 等保持原样,不被转义。
- R4 已转义的 `\$` 不重复处理。
- R5 宽 display 公式横向滚动而非溢出页面;`\tag` 编号回到公式真实右缘、不再压住内容。
- R6 连续 display 公式之间间距更舒展。
- R7 公式 CSS 修复进入项目自带样式(`global.css`),对所有用户/默认主题生效,而非仅依赖本地 `user.css`。
- R8 安全不回退:不改 CSP、不放宽 sanitize、不向 shell 传文档内路径(本任务不触及这些路径)。

## Out of Scope

- 不改 array 内部 `\\` 行间距(属文档内 LaTeX,逐行间距由作者控制)。
- 不引入新的数学引擎或替换 remark-math。
- 不处理 `$` 后无小数点的纯整数货币(如 `$5`),因与数字开头真公式不可区分且样本中不存在;必要时用户可手动 `\$` 转义。
